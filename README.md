# homebrew-boombox

A [Homebrew](https://brew.sh) tap for [boombox](https://github.com/danySam/boombox),
a Spotify client for the terminal.

```console
brew install danySam/boombox/boombox
boombox setup
```

Built from source with streaming enabled, so boombox appears in Spotify's
device list and can play the audio itself. It needs Spotify Premium and a
Spotify developer app of your own; `boombox setup` walks you through both.

Issues and pull requests belong on the
[main repository](https://github.com/danySam/boombox).
